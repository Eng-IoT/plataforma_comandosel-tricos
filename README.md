# Plataforma Comandos Elétricos Industriais

Plataforma de microaulas e simuladores interativos para formação em comandos elétricos industriais.

## Execução
Abra `index.html` em navegador moderno. A versão V7 disponibilizada é autônoma (HTML com recursos incorporados).

## Segurança
As simulações são didáticas; intervenções reais exigem procedimentos e supervisão qualificada e atendimento às normas aplicáveis.
